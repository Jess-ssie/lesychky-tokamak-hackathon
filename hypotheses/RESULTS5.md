# RESULTS5.md — чи можна підкрутити модель під неонові зриви (post-hoc)

Запуск 2026-10-10. Критеріїв наперед не записано, тому це спостереження, а не перевірена гіпотеза.
Скрипт: `research/neonsweep.py`.

## Питання

Найбільше запізнілих тривог дають неонові зриви. У моделі за них відповідає один параметр `neon_p`:
імовірність зриву у вікні після вимкнення нагріву, якщо команда клапана неону перевищувала 0,7. Що буде, якщо його збільшити?

## Перебір параметра (2300 розрядів: seed 101, 102, 202 і набір команди на 200; Lead time 0,3 с)

| `neon_p` | Спіймано при 5 % | при 10 % | Неонових зривів спіймано при 5 % (з 198) | Хибних тривог серед безпечних неонових (з 311) | M по сітці |
|---|---|---|---|---|---|
| 0 | 61,9 % | 76,6 % | 30 % | 3,2 % | 0,663 |
| 0,20 | 63,5 % | 77,8 % | 35 % | 5,5 % | 0,682 |
| 0,35 | 63,1 % | 78,4 % | 38 % | 7,1 % | 0,696 |
| 0,40 (у здачі) | 62,0 % | 78,6 % | 38 % | 7,4 % | 0,695 |
| 0,50 | 60,7 % | 78,6 % | 40 % | 8,4 % | 0,693 |
| 0,60 | 58,0 % | 72,6 % | 41 % | 9,6 % | 0,680 |
| 0,75 | 54,7 % | 64,4 % | 46 % | 11,6 % | 0,650 |
| 0,90 | 42,9 % | 47,9 % | 56 % | 18,0 % | 0,601 |

Більший параметр ловить більше неонових зривів, але загальний результат падає: розряд із сильним неоном виживає у 65 % випадків,
і тривоги на таких розрядах з'їдають бюджет, через що поріг піднімається й губляться зриви за густиною та низьким q95.
Оптимум лежить біля виміряної частоти зриву в неоновому вікні (0,35; гіпотеза N1).

## Спроба перейти на 0,35 (версія v2.3) — відхилено

| Набір | v2.2 (`neon_p` 0,40) | v2.3 (`neon_p` 0,35) |
|---|---|---|
| 2300 розрядів, 0,3 с, 5 % | 62,0 % | 63,1 % |
| Офіційний Test run, seed 1, 0,3 с, 5 % | 42 з 58 | 42 з 58 |
| Розряди з Test run команди, 0,3 с, 5 % | 44 з 63 | 43 з 63 |
| Розряди з Test run команди, 0,3 с, 15 % | 58 з 63 | 56 з 63 |

Різниця в межах розкиду й не має сталого знака. У здачі лишається v2.2.
Для рядків «Test run команди» модель прогнано нашим кодом по каналах із файла прогону;
відтворення колонки `p` для v2.2 збігається із симулятором з точністю 0,011.
