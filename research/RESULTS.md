# Порівняння моделей

Метрика: середній TPR по сітці Lead time (0.03–2 с) × FPR (2–30 %), спонтанні зриви виключено.
Навчання: 1200 розрядів (seed 101). VAL: 600 розрядів (seed 202), на ньому обиралася епоха зупинки.
TEAM200: 200 розрядів команди, у навчанні й доборі не брали участі.

| Модель | VAL | TEAM200 |
|---|---|---|
| Фізична формула v2 (у здачі) | 0.671 | 0.755 |
| GRU поверх фізичної (поправка до логіта) | 0.699 | 0.754 |
| GRU на ознаках разом із формулою | 0.656 | 0.730 |
| GRU без формули, покрокова мітка | 0.615 | 0.614 |
| GRU без формули, втрата по розряду | 0.547 | 0.544 |
| Градієнтний бустинг, 25 ознак | 0.49* | — |

\* для бустингу метрика рахувалася з колонкою FPR 0 %, тож число не цілком порівнянне.

Скрипти: `nnprep.py` (ознаки), `nntrain.py` (GRU, покрокова BCE), `nnmil.py` (втрата по розряду, поправка до фізики), `gb.py` (бустинг).
